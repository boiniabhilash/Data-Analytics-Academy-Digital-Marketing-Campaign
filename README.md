Data Analytics Academy — Digital Marketing Campaign Portfolio
##What this project is
This is a portfolio-based digital marketing campaign simulation for a hypothetical Indian online education brand, Data Analytics Academy.

The work demonstrates an end-to-end digital marketing workflow:
Research → Audience → Funnel → Meta Campaign → Content → Creatives → Landing Page → Lead Capture → Retargeting → Nurturing → Measurement → Optimization → Case Study.
##What is real vs simulated
*The strategy, campaign architecture, audience framework, copy, creative concepts, landing-page prototype, tracking framework and nurture workflow are portfolio deliverables.
*The brand is hypothetical.
*The ₹50,000 media budget is a planning assumption.
*No live paid Meta campaign was executed for this portfolio project.
*No leads, enrollments, revenue, ROAS, CTR, CPC or CPL are presented as actual campaign results.
*Any KPI scenario is explicitly labeled as hypothetical.

##Tools
Meta Ads Manager (planning), Canva/Figma (creative design), Excel (planning and measurement), Google Trends (research), GitHub (portfolio presentation).
