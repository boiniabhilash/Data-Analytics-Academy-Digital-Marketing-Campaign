# KPI Framework

> Converted from the original Excel planning workbook into GitHub-readable Markdown.

## KPIs

| Stage | KPI | Definition | Optimization Use |
| --- | --- | --- | --- |
| Awareness | Impressions | Times ads displayed | Delivery scale |
| Traffic | CTR | Link clicks / impressions | Creative/message |
| Traffic | CPC | Spend / link clicks | Creative/audience |
| Landing Page | LP Conversion Rate | Leads / LP visitors | Offer/page/form |
| Lead | CPL | Spend / leads | Acquisition efficiency |
| Quality | Qualified Lead Rate | Qualified leads / total leads | Targeting/message |
| Quality | CPQL | Spend / qualified leads | Quality-adjusted acquisition |
| Conversion | CAC | Spend / new customers | Overall economics |
| Revenue | ROAS | Revenue / ad spend | Revenue efficiency |

## Funnel

| Event | Definition |
| --- | --- |
| landing_page_view | User reached landing page |
| cta_click | User clicked CTA |
| form_start | User began registration |
| lead_submit | Registration completed |
| qualified_lead | Lead met qualification criteria |
| workshop_attended | Lead attended workshop |
| course_interest | Lead showed course interest |
| enrollment | Lead became customer |
