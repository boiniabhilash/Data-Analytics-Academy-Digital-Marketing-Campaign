# Optimization Framework

> Converted from the original Excel planning workbook into GitHub-readable Markdown.

## Signal

| Signal | Likely Issue | Action |
| --- | --- | --- |
| Low CTR | Weak hook/creative | Test new hooks, formats and messages |
| High CPC | Low relevance/weak creative | Improve creative/copy or audience |
| High clicks + low LP conversion | Landing page mismatch | Improve headline, offer, CTA or proof |
| Low form completion | Friction | Reduce fields / clarify value |
| High CPL | Weak ad or LP | Optimize ad + LP |
| Many leads + low quality | Targeting/message mismatch | Refine audience, message and form |
| Good qualified leads + low enrollment | Nurture/sales issue | Improve follow-up and course consideration |
| High CAC | Funnel economics issue | Optimize whole funnel |
| High frequency + declining CTR | Creative fatigue | Refresh creative/audience |
| Good CTR + poor lead quality | Click curiosity | Improve qualifying message |

---
*Portfolio note: this document is a planning artifact for a campaign simulation. It does not represent live Meta campaign performance.*
